# Blog Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** Add an MDX-authored, SEO-friendly blog (`/blog`, `/blog/category/[slug]`, `/blog/[slug]`, `/blog/rss.xml`) styled with the landing theme.

**Architecture:** `src/lib/blog.ts` reads `src/content/blog/*.mdx` with `gray-matter` at build time; pages are static Server Components rendering MDX via `next-mdx-remote/rsc`. Only `PostGrid` (Load more) and `ShareButtons` (copy link) are client components.

**Tech Stack:** Next.js 15 App Router, TypeScript, Tailwind v4, next-mdx-remote, gray-matter.

**Spec:** `docs/superpowers/specs/2026-10-09-blog-design.md`

## Global Constraints

- No test suite: each task verifies with `npm run lint` and `npm run build` (never while `npm run dev` runs).
- Desktop-first breakpoints only: `max-lg:` (≤980), `max-md:` (≤700), `max-sm:` (≤359).
- Existing colour/font tokens only; state/prose CSS goes unlayered in `globals.css`.
- Landing page markup unchanged except the added "Blog" nav/footer link.
- Drafts excluded when `NODE_ENV === "production"` everywhere (lists, pages, sitemap, RSS).

## Review Focus

1. Zero published posts (production with only drafts) → `/blog` builds and shows "Posts coming soon."; sitemap/RSS valid; category pages with no posts not generated.
2. Invalid frontmatter (unknown category, bad date, missing cover) → build fails naming file + field.
3. Copy link where `navigator.clipboard` is unavailable → no crash; falls back to `execCommand` or shows nothing.
4. Fewer than 3 related candidates → shows what exists; section hidden when none.
5. Post titles with `<`/quotes → JSON-LD escaped (`<`), share URLs encoded.
